A Python program that writes the funniest one-line excuse a robot vacuum can give for missing a spot — 69 characters, deadpan, with the punch at the end — to `/output/entry.txt`. The line was picked by calibrating 32 hand-written candidates plus 3 stock-joke controls against the judge brief's five criteria (on-topic excuse, real laugh, deadpan machine voice, surprise, tightness).

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=. python3 main.py`).
